File Formats Explained

📄 HTML

View in any web browser. Best for reading online and sharing via link. No download needed.

📊 PowerPoint (PPTX)

For live presentation. Editable, easy to customize for your context. Works with PowerPoint, Google Slides, or Keynote.

📋 PDF

Download and print or view offline. Best for distributing handouts. Looks consistent across devices.

🔧 Source Files (Quarto)

In the GitHub repository. Editable markdown source files if you want to modify content or styling.
