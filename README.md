# AI in Pedagogical Design and Delivery

A workshop and resource collection for building AI literacy among marketing and management faculty in higher education.

## Overview

This repository contains materials for a hands-on workshop designed to help educators understand and integrate AI tools into their pedagogical design and delivery practices. The approach emphasizes practical application over technical expertise, making AI accessible to faculty with varying levels of experience.

## Workshop Structure

- **Duration:** 2 hours
- **Audience:** Marketing and Management faculty
- **Format:** Interactive presentation with hands-on activities

### Core Components

1. **Welcome & AI Landscape** - Overview and context setting
2. **Automate the Tedious** - Hands-on summarization activity
3. **The Art of the Prompt** - CRAFT framework and prompt engineering
4. **5-Step Critique Framework** - Quality control for AI outputs
5. **Assessment Stress-Test** - Testing assignments against AI
6. **Secure, Safe & Sustainable AI** - Responsible use considerations
7. **Wrap-Up & Next Steps** - Resources and continued learning

## Quick Start for Participants

1. Read `what-to-expect.md` (3 minutes)
2. Review `quick-start-guide.md` (5 minutes)
3. Bring a laptop and one assessment idea to the workshop

## Building the Presentation

This project uses [Quarto](https://quarto.org/) to generate presentations and documents:

```bash
# Install Quarto (if not already installed)
# https://quarto.org/docs/get-started/

# Render the presentation
quarto render ai-pedagogy-presentation.qmd

# Render all documents
quarto render
```
